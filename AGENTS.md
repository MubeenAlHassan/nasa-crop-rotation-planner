# Project Mandate: Field Shift (NASA Space Apps 2026)

You are building a Farmer-Centered Crop Rotation Decision-Support Tool powered by NASA Earth Observation datasets (SMAP, ECOSTRESS, GPM, Landsat, MODIS, NASA POWER, GRACE-FO, SRTM, GEDI).

## Mandatory Context & Architecture Files
Before designing features, writing data pipelines, building ML/SI models, or creating UI components, **you must read and adhere to these files in the repository**:
1. `docs/context/challenge_context.md` — Official requirements, required datasets, 3-way rotation comparison rules, and human-in-the-loop constraints.
2. `docs/context/video_context.md` — NASA Johnson Space Center SME evaluation criteria (multi-scale fusion, visible uncertainty, trade-off matrices).
